# mini-gpt-from-scratch

## 项目学习目标

从零学习并逐步实现一个教学型 Decoder-only MiniGPT，理解数据处理、Transformer 结构、训练和自回归生成的完整流程。

## 当前状态

当前仅完成项目骨架，所有功能均未实现。

## 后续模块学习顺序

1. 下载和读取文本数据
2. 数据集划分
3. 字符级 Tokenizer
4. Dataset 和 DataLoader
5. Token Embedding
6. Position Embedding
7. Q、K、V 线性投影
8. Causal Self-Attention
9. Multi-Head Attention
10. FFN
11. Transformer Block
12. MiniGPT 模型
13. 损失函数
14. 训练循环
15. Checkpoint
16. 自回归文本生成
17. Temperature、Top-k、Top-p
18. 模型评估和可视化
